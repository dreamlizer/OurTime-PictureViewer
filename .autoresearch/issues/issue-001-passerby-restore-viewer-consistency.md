# 路人恢复与照片浏览一致性

## 目标

让路人卡片、人物详情、人物照片序列和大图浏览使用同一套“当前有效照片”口径；路人可从卡片或详情恢复到人物档案；任何照片加载失败时都不显示上一张照片。

## 范围

- `browse_queries.py`：人物列表只统计当前有效照片中的人脸。
- `app.py`：人物详情、状态统计和恢复语义与有效照片口径一致。
- `web/app.js`：路人卡片增加直接恢复入口，详情按钮文案明确，照片打开失败时保留人物弹窗。
- `web/viewer.js`：关闭后重新打开先清空旧图，最终失败不残留旧图。
- `validation/`：隔离数据库、真实 Chrome、宽窄屏和失败图片回归。

## 完成判据

1. 被目录排除的照片不会出现在人物/路人列表的数量、封面、详情或人物照片序列中；恢复目录后自动重新出现。
2. 系统生成的“路人”恢复后变成未命名待识别人物；已有姓名的人标为路人再恢复时保留姓名和确认状态。
3. 路人卡片和详情均可恢复；单张恢复只移动该张脸。
4. 图片请求失败时不残留上一张图片，也不出现“新元数据配旧图片”。
5. 隔离 API、真实浏览器、现有 smoke 和正式入口只读检查均有明确结果。
