# 拾光相册

本机照片整理工具：记录位置、人物、时间和地点。浏览器只是界面，后台和资料库都在本机。原照片不移动、不删除、不回写 EXIF。

它不是云相册，也不能代替原图备份。

## 怎么打开

1. 双击 **启动拾光.vbs**，浏览器打开 http://127.0.0.1:8765 。
   有照片时先进入首页推荐；侧栏「全部照片」仍是原来的时间流。
2. 点「添加照片」，选择本地文件夹，再点「添加并扫描」。选文件夹不会立刻扫描。
3. 在人物档案里命名、合并；大图里可以收藏、改地点、导出带标签的成品。国内照片地点按离线行政区划显示为“省/直辖市 · 市 · 区县 · 街道或具体地点”，省略“中国”并自动去掉直辖市重复层级。地图框选会根据实际选中照片给出共同的行政区建议；跨区退到市、跨市退到省、跨省不强行猜名。人工地点仍优先于 GPS 自动地点。
4. 不用时双击 **停止拾光.vbs**。

源码方式：Windows + Python 3.12，在本目录创建 .venv，安装 requirements.txt，再用上面的启动器。维护者可双击 `打包拾光.cmd` 生成包含运行时、人脸模型、离线地名库、ExifTool 和导出浏览器的 Windows 绿色压缩包；包内不含现有 `data/` 或照片。

## 首次使用

1. 把程序放到可写目录。
2. 人脸模型、地名数据和 ExifTool 按 docs/SETUP.md 放到 resources/ 或在 config.local.json 里指定。
3. 只扫描你明确选择的文件夹。
4. 人物结果需要人工核对，不会自称百分百正确。

没有模型时仍可先添加照片；页面会说明缺了什么，不会假装识别完成。

## 浏览与撤销（新版源码）

同一浏览器标签页会记住已浏览页面的筛选和照片位置，刷新、切换回来或浏览器前进后退时恢复。照片集合发生变化、原位置无法核对时，保留筛选并重新显示列表，不强行跳到错误照片。

「整理 → 最近操作」以及照片、人物详情里的「最近操作与撤销」，可撤销新版页面提交的照片补录、照片附近地点修改和人物合并。撤销只恢复相关人工资料或人物分组，不修改原照片；相关字段有后续修改时会拒绝整次撤销。旧补录、缓存清理和地图框选自动地点规则不列为可撤销操作。

新撤销接口需要后台加载新版源码；旧后台仍可补录，但页面会明确说明当前不支持撤销。

## 人名标签排版

中文竖版默认使用“智能排布”：同图按已命名人物的典型脸高统一倍率，并随照片当前显示大小同比缩放，最小保持 1 倍，最多放大至 1.6 倍；默认靠左并略微下沉。人脸这一排的右侧外缘人物，内侧拥挤且外侧可在相近高度贴近本人放下标签时，优先向右外排；不是按姓名或照片写特例。偏左、偏右、偏上、偏下仍可单独选择。

三类遮挡分别计算，不能混用比例：任意两标签的重叠面积不得超过较小标签面积的 5%；单个标签覆盖一张人脸的面积不得超过该人脸框面积的 35%；估算眼部区域单独避让，不因为人脸遮挡低于 35% 就允许挡眼。库内没有眼睛关键点，眼部按脸框横向 18%–82%、纵向 22%–52% 估算，不能宣称精确识别眼睛。以上限制优先于靠左偏好。

智能排布在头侧附近小幅调整，联合选择左右位置，不通过大幅上下漂移或隐藏姓名来凑空位。有限候选中未找到同时满足限制的排布时，标签样式面板会明确提示具体超标项，供手动微调，不冒充已达标。已有自定义位置即使超标也保留并提示。

标签挤到邻人或离邻人更近时，优先在原侧向本人收近，必要时允许少量压住本人脸框边缘，避免把遮挡转嫁给旁人；空间宽裕时仍保留原间距。眼部区域按上述估算规则保护。

默认风格的文字方向初始为“自动（中文竖排、英文横排）”。纯英文名横排，中文和中英混合名竖排。素笺和茶棕各用一张竖牌，按文字长度拉长直边中段，两端角花保持原样；留白随同一缩放系数，不按字数换图。横排使用各自的横牌，规则相同。旧版方向偏好首次升级时回到自动；此后主动选择横排或竖排仍会保存。大图顶栏和人名标签详细菜单里都有这个方向选项，两处改的是同一个设置。方向设置与照片的自定义坐标独立。

已有手动位置的照片自动使用“自定义排版”；拖动标签后自动保存并切入自定义，没有手动记录时该选项置灰。切换到智能或其他方向仅改变显示，不清除自定义；切回即可恢复。未拖动的标签继续自动排布。只有“清除本张自定义排版”会删除本张手动位置。排版选择在当前页面会话按照片记住，刷新后有保存位置的照片优先使用自定义。原照片不修改。

## 数据放在哪里

自动地名匹配以已知省份和 GPS 行政区边界约束同名候选，不会因为缺少本地同名条目就采用外省街镇。无法确定细名时退到已知行政区；GeoNames 与 OpenStreetMap 来源分别标注。已有跨省错误自动地点可用 `tools/repair_place_conflicts.py --report <清单路径>` 只读生成清单，增加 `--apply` 才会备份后修正；跳过人工地点、扫描运行时拒绝执行，逐张保留审计记录。

资料库、缩略图、人脸裁剪在 data/。原照片仍在原来的文件夹。页面「备份资料库」写到 data/backups/。

绿色软件形态是：一个启动入口 + 程序文件夹 + 可选的用户数据文件夹。换电脑时带走原图和完整 data/ 即可继续。JSON 导出只是清单，不含完整人脸特征，不能当完整恢复包。

## 支持范围

目前按 Windows、本机浏览器验证。地图底图需要联网；照片和人物信息不会主动上传。其他系统未验证。

已知限制：只归并内容完全相同的文件；人脸阈值是初始规则；RAW/HEIC 取决于本机组件；物体识别未作为对外功能开放。
