# 拾光相册

本机照片整理工具：记录位置、人物、时间和地点。浏览器只是界面，后台和资料库都在本机。原照片不移动、不删除、不回写 EXIF。

它不是云相册，也不能代替原图备份。

## 怎么打开

1. 双击 **启动拾光.vbs**，浏览器打开 http://127.0.0.1:8765 。
2. 点「添加照片」，选择本地文件夹，再点「添加并扫描」。选文件夹不会立刻扫描。
3. 在人物档案里命名、合并；大图里可以收藏、改地点、导出带标签的成品。国内照片地点按离线行政区划显示为“省/直辖市 · 市 · 区县 · 街道或具体地点”，省略“中国”并自动去掉直辖市重复层级。地图框选会根据实际选中照片给出共同的行政区建议；跨区退到市、跨市退到省、跨省不强行猜名。人工地点仍优先于 GPS 自动地点。
4. 不用时双击 **停止拾光.vbs**。

源码方式：Windows + Python 3.12，在本目录创建 .venv，安装 requirements.txt，再用上面的启动器。维护者可双击 `打包拾光.cmd` 生成包含运行时、人脸模型、离线地名库、ExifTool 和导出浏览器的 Windows 绿色压缩包；包内不含现有 `data/` 或照片。

## 首次使用

1. 把程序放到可写目录。
2. 人脸模型、地名数据和 ExifTool 按 docs/SETUP.md 放到 resources/ 或在 config.local.json 里指定。
3. 只扫描你明确选择的文件夹。
4. 人物结果需要人工核对，不会自称百分百正确。

没有模型时仍可先添加照片；页面会说明缺了什么，不会假装识别完成。

## 数据放在哪里

资料库、缩略图、人脸裁剪在 data/。原照片仍在原来的文件夹。页面「备份资料库」写到 data/backups/。

绿色软件形态是：一个启动入口 + 程序文件夹 + 可选的用户数据文件夹。换电脑时带走原图和完整 data/ 即可继续。JSON 导出只是清单，不含完整人脸特征，不能当完整恢复包。

## 支持范围

目前按 Windows、本机浏览器验证。地图底图需要联网；照片和人物信息不会主动上传。其他系统未验证。

已知限制：只归并内容完全相同的文件；人脸阈值是初始规则；RAW/HEIC 取决于本机组件；物体识别未作为对外功能开放。

## 反馈

请不要上传原图、人脸库或未脱敏日志。安装见 docs/SETUP.md，数据边界见 docs/PRIVACY-AND-DATA.md。
