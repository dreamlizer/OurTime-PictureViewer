# 标签遮挡规则实际交付

本轮修改 `web/viewer.js`，不修改资料库或原图。

| 对象 | 计算方式与限制 |
| --- | --- |
| 任意两个标签 | 交集面积 / 较小标签面积，不超过 5% |
| 单个标签与一张人脸 | 交集面积 / 该脸框面积，不超过 35%；偏好减少旁人遮挡并贴近本人 |
| 眼部 | 按脸框横向 18%–82%、纵向 22%–52% 估算眼部带，单独避让；库内没有眼睛关键点 |

原先智能排布错用标签间 35% 阈值，旧方向排布另用 12%，现统一为 5%。人脸比例不再使用“标签与脸中较小面积”作为分母。

新增有限候选的联合选择，优先筛除眼部遮挡、人脸超限和标签间超限，再比较贴近本人、轻微上下调整及左右偏好。同一排的右侧外缘人物，在内侧存在近邻且外侧有安全的同高度位置时可向外右排，不按姓名或照片编号写特例。

候选无解或保存的自定义本身超标时，样式面板显示具体问题；不隐藏名字、不覆盖自定义、不把未达标状态报成有效排布。此机制不宣称有限搜索能解出所有极端密集合影。

## 验证结果

- `validation/validate_label_limits.py`：5 张实图 × 2 个窗口尺寸 × 茶棕/默认两种风格，20 组均通过。标签对最大重叠 4.5688%，单标签对单脸最大遮挡 26.6910%，估算眼部重叠为 0。
- 两张王珊珊晚餐照片（102377、102381）的所有组合均排右；此前许惠暖案例仍排左。
- `validation/validate_face_label_drag.py`：33 项通过，含拖动、保存失败回退、切换智能/自定义、清除失败保护及导出。
- 注入冲突自定义到一次性浏览器内存：两标签保持原位置，面板明确显示重叠 100% 超标；不写正式库。
- 正式页面示例重排耗时约 20ms（单次测量，不是性能基准）。
- `validation/smoke.py`：24 项通过，静态阈值检查同步为 5%/35% 并要求独立眼部函数。

证据：`validation/reports/label-overlap-20260919/metrics.json`、`status.json`、各照片实图截图。
