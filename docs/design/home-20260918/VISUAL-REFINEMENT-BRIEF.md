## 4. 任务 A：修正文位置及尺度

### 必须先定位

采集 sidebar、main、#home-view、.home-discovery、.home-heading、.home-tabs、.home-hero、.home-pair 的 bounding rect 与 display/width/max-width/margin/padding/position/transform/grid 配置。

检查父级是否宽度异常、重复侧栏偏移、继承其他页面类、隐藏元素占布局，以及过期样式。不能用负 margin、translateX 或写死 left 来把照片“拉回来”；不要堆更多 !important 掩盖级联冲突。

### 目标布局

- 标题、类别切换、主图左边、下排左卡共用左对齐线；日期与内容右边对齐。
- 正文在**扣除侧栏后的可用区域**居中，左右留白均衡。设一个统一容器，不让标题和照片分别算宽度。
- 普通桌面建议内容宽度 `min(可用宽度减两侧内边距, 1440px)`；横向内边距可在 32–64 CSS px 浮动。以真实 CSS 视口为准，不拿截图物理像素直接填 CSS。
- 超宽屏可以保留对称留白，不强行把图铺到 3000px；不能保留截图中一边巨大空白、一边很窄的形态。
- 主区域约 62:38，列间距约 32px；图像 16:10 左右，文字靠近图像，垂直居中。按实际照片调整，不设全屏高度。
- 下排两栏等宽，间距 24–32px；两栏媒体区顶边和底边对齐。人物拼图应填满媒体区，不让空底撑齐高度。
- 首页 h2 建议 30–34px；主组标题 32–38px；下排标题 20–24px；说明 14–15px。使用当前字体和配色，避免把所有文字都放大。
- 日期改为紧凑两层：`9月18日` / `2026年 · 星期五`，使用真实日期数据。
- 首页内可隐藏重复面包屑，但不要影响其他页顶栏与原有“添加照片”入口。不要给首页加第二层导航条。
- 900px 附近转单列；390px 不横向溢出，人物拼图可保留紧凑多栏或改 2×2，只要主角可辨、年份可读。

## 5. 任务 B：修人物卡结构与年份合同

### B1 消除空底与选择器冲突

把“媒体框”“照片格”“操作层”分成明确类名。示例：`.home-years` 负责整体尺寸，`.home-year-photo` 负责照片格，`.home-card-tools` 仅做绝对定位覆盖层或放到媒体区之外。

不能继续用 `.home-years span` 匹配所有后代。仅四个照片单元参与网格，工具不占格、不继承 aspect-ratio。图片单元 height/min-height/object-fit 与父网格一致；不足四张按实际张数排列，不造空占位。

“换一组 / 暂时不推荐”放在媒体区右上工具层或省略号菜单；hover、键盘 focus 和触屏都可访问，不依赖鼠标才能发现关键动作。点击工具不触发打开照片组。保留现有恢复隐藏入口。

### B2 封面与年份绑成一个数据对象

推荐返回结构化封面数组，例如：

```json
{"covers":[{"asset_id":123,"year":"2002","target_face_id":456}]}
```

字段命名可调整。year 必须由该 asset 的有效日期计算，target_face_id 如存在必须属于卡片人物且关联此 asset。前后端同步调整，必要时保留旧 cover_asset_ids 兼容，不能引入两份各自排序的数组。

封面选择兼顾最早、最晚与中间分散年份，最终从左到右按年份升序排列；优先选择接近整个跨度 1/3、2/3 位置的已有年份，不连续拿最早四年。去重、备用图替换后仍以完整对象操作，不能图改了年份没改。

无可信年份则不标年份；不能拿组开始年、完整年份列表的下标或默认年份代替。

### B3 让主角可辨认

人物选图在该人物组内进行，优先目标人物脸框较大、位置适合裁切、人数较少且预览可用的照片。通用“有人脸”不等于“目标人物清楚”。复用现有 bbox/脸裁剪数据，不重识别、不建立新模型任务。

优先呈现带适量环境的面部/半身照片。多人合影按目标脸框确定 object-position 或安全裁切范围；不是在前端随意放大整图。先核实 bbox 坐标系、EXIF 旋转和缩略图几何一致性。

若安全裁切无法保证，使用已有目标人物人脸预览并保留点击原照片组能力；若预览不可用则换同年候选，最后才保留完整原图。照片分辨率不足不硬放大成模糊大脸。未知身份时不能裁另一个人的脸填空。

## 6. 任务 C：按类别选封面，保留真实标题

拆分选图策略，保持组成员与快照查询不变：

- 往年今日：当前夕阳主图可以保留这种方向。以当天真实内容、可用预览、收藏和构图适配为依据，不需要强行有人脸。
- 重访地点：优先横向、预览可用、收藏以及环境可见的候选；取消无条件“有人脸优先”。已有可靠场景标签可作弱提示，但缺标签不能淘汰全组，也不新增物体识别扫描。
- 人物这些年：按任务 B 的目标人物可见度选择。

仅凭人数和长宽比无法知道一张图是不是风景，不宣传自动找出“最美地点”。有可靠地点信息但全组都是日常人物照时，仍可展示，文案如“在沈河区的片段”；不要把吃饭照片硬说成旅行或景点。

地点标题分层：主要显示“沈阳 · 沈河区”，完整“辽宁省 · 沈阳市 · 沈河区”保留在辅助信息/可访问说明。展示可以简短，分组键必须继续用完整有效地点，不能把重名地点合并。

补充准确日期范围，例如“2024年1月12日–14日 · 141张”；此例是假设格式，必须使用组的真实首尾日期。只有月级信息时按实际精度显示。不要新增描述经历、关系或感受的文字。

主图右侧可以将数量写成“这一天留下了 4 张照片”，但不靠长句填空。首先通过正确比例、文字尺度和间距解决稀疏感。
