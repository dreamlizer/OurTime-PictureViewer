# 拾光首页设计 · 2026-09-18

状态：布局设计稿，尚未替换正式首页。三个功能全部保留，选择的是布局，不是功能取舍。

## 入口与返回

- 左侧新增「首页」，首次打开进入首页；现有「全部照片」保留。
- 首页包含「往年今日」「重访地点」「人物这些年」三个可点击区域。顶部可以切换查看其中一个类别的更多推荐，或回到综合推荐。
- 综合推荐每次呈现约 3–5 组，同一天固定，用户可主动「换一组」。换组按类别轮换，不强迫整页全部改变。
- 点击某组进入该组的完整照片列表，再点照片进入现有大图。标题显示实际日期、地点或人物，返回时回到原卡片。不能只把封面的三张预览当成全部照片。
- 首页推荐和人工整理分开；不新增手工相册、聊天框、统计看板或扫描任务。

## 三个推荐方向

| 方向 | 选取规则 | 展示与无内容处理 |
| --- | --- | --- |
| 往年今日 | 往年相同月日，使用可靠拍摄日期或精确到日的人工日期 | 按年份分组；没有同日时明确改为「那年这个月」，不把日期附近照片称为「今日」 |
| 重访地点 | 同地点或邻近 GPS，按连续拍摄日期分段；先用保守分组 | 显示真实日期范围与共同地点；跨城市不合并为一个地点，不自动断言是旅行 |
| 人物这些年 | 已命名且非路人的人物；封面从不同年份选择 | 点击后看这个人物的完整时间线；仅一个年份时显示「与某人的片段」，不伪造跨度 |

不需要接入大模型，也不需要重新识别人脸。只使用已有元数据、人工标注和已确认的人物关联。

## 推荐质量

1. 排除已排除照片、没有可用文件的照片，以及截图、小图；完全相同的内容按档案去重。
2. 文件修改时间不能用于「往年今日」。日期精度不足时使用真实精度，只有年份的照片可显示为「某年的片段」。
3. 封面优先收藏、可用预览、尺寸足够的照片。按日期与人物分散取样，避免一次连拍占满卡片。这不是审美评分，不宣传「最佳照片」。
4. 同一张照片不要占用首页多个封面；近期推荐过的组降低优先级，人物与地点轮换。
5. 提供「暂时不推荐」，记录只存本机。不推断亲属、伴侣、同事关系，不自动编写经历和感受。
6. 单类没有合适内容就收起；用收藏作为补充。整个库很少时直接提供全部照片入口，不出现一排空卡片。
7. 推荐候选在后台生成有限数量并缓存，不在首页下载全库人物或扫描全库原图。照片组查询必须保持同一范围和稳定分页。
8. 大图、人物、地点的现有浏览能力继续复用；新首页只增加发现入口。
